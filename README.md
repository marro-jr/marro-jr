## 🚀 Featured Projects

### 📱 Smart Device Analytics Platform — Microsoft Fabric

End-to-end **Data & Analytics platform** built with Microsoft Fabric for processing and analyzing data from more than **24,000 smart devices**.

**Technologies:** Microsoft Fabric · PySpark · Delta Lake · Dataflows Gen2 · Pipelines · Lakehouse · Warehouse · Power BI

- 🥉 Bronze → raw data ingestion
- 🥈 Silver → cleaning and transformations
- 🥇 Gold → analytical tables
- ⚙️ Parameterized notebooks and pipelines
- 🔄 Incremental processing
- 📊 Semantic model and Power BI dashboard

🔗 **[View project on GitHub](https://github.com/marro-jr/smart-device-analytics-fabric)**

---

### ☁️ Modern Data Warehouse — Azure

Data Engineering solution built on **Microsoft Azure** for analyzing customer churn across approximately **7,000 customers**.

**Technologies:** Python · Pandas · Azure Data Factory · ADLS Gen2 · Azure SQL · Parquet · Power BI

- 🐍 ETL processes with Python and Pandas
- 🗄️ Azure Data Lake Storage Gen2
- ⚙️ Pipeline orchestration with Azure Data Factory
- ⭐ Dimensional modeling with Star Schema
- 🔁 Idempotent data loads
- 📊 Customer churn analysis in Power BI

🔗 **[View project on GitHub](https://github.com/marro-jr/modern-data-warehouse-azure)**
